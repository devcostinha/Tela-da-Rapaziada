# Tela da Rapaziada

Compartilhamento de tela para Windows, com salas persistentes no perfil local e WebRTC P2P pela Radmin VPN.

## Download

[Baixar a versão mais recente](https://github.com/devcostinha/Tela-da-Rapaziada/releases/latest)

Baixe o instalador **Tela-da-Rapaziada-Setup-VERSÃO.exe**. A partir da versão 0.3.1, o app verifica atualizações ao abrir e oferece **Atualizar** ou **Agora não**. Ao atualizar, ele baixa o instalador, verifica o download, instala e reinicia. Perfil e salas permanecem neste PC.

GitHub hospeda somente arquivos de distribuição. Suas telas, áudio, convites e perfis não são enviados ao GitHub.

## Conectar os amigos

Instale o Radmin VPN pelo botão do app. Rede: **Tela da Rapaziada**; senha: **Tela12345**. Todos devem estar na mesma rede. Se algum amigo não aparecer, use a conexão direta por IP no diagnóstico e permita o app no Firewall do Windows.

Windows 10/11 x64. O isolamento de áudio por processo exige Windows 10 build 20348 ou superior. Discord no navegador não pode ser excluído separadamente do restante do navegador.

Os instaladores ainda não possuem assinatura digital comercial.
